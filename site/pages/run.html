Run it

Run HPay on your machine

You need Docker, Go, Node 20 or newer, sqlc 1.27 and golang-migrate. The full steps with troubleshooting are in the setup guide.

Backend

Starts Postgres and Redis, applies the migrations, loads demo data and serves the API on port 8080.

# from the repository root
cd src/backend
cp .env.example .env
docker compose up -d
sqlc generate
make migrate-up
make seed
go run ./cmd/server

Admin console

Opens on port 5173.

cd src/admin
npm ci
npm run dev

Demo logins, created by the seed with --e2e-admins: e2e-checker@HPay.dev (superadmin) and e2e-maker@HPay.dev (operations). Password E2ETest@123. These exist only in demo data.

Mobile app

Expo. Set the API address to your machine, not localhost, if you use a phone.

cd src/mobile
npm ci
npx expo start

Demo customer: 0900000001 with password Demo@123.

Tests

# backend, in Docker (also works where Go-built programs are blocked)
.\scripts\test-backend.ps1
.\scripts\test-backend.ps1 -GoArgs "./internal/ledger -race -count=1 -v"

# admin
cd src/admin && npm run lint && npm test && npm run test:e2e

# mobile
cd src/mobile && npx tsc --noEmit && npm run lint && npm test
