Honest notes

What is not finished, and what is not proven

A project is easier to trust when it states its own limits. These are the ones known today. The living lists are the backlog and the open admin issues.

Not proven yet

Mobile

Not run on a physical phone

The app is covered by 255 automated tests, type checks and lint, but it has not been run on a real device. There are no phone screenshots on this site for that reason.

Messaging

Real SMS never sent

The sender for one-time codes is written and checked against its configuration, but it has not been called with real provider keys. Demo environments return codes in the response.

Performance

Numbers are noisy

One laptop in Docker, one run per column. After the PIN change, accepted payments per second rose but end-to-end time got worse. Twelve failed transfers in the latest run are not yet explained.

Security

No rotation drill

PIN secrets can be rotated by design and by test, but a rotation has not been rehearsed against a real secret manager. No external penetration test has been done.

What this project is not

HPay is a demo built to show how a payment product can be designed, tested and documented. It has no licence to hold money, no real bank or card connection, and no real customers. All data shown is seeded demo data.
