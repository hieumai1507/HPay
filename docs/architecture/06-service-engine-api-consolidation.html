⚡ 06 — Plan Kế hoạch Tái cấu trúc & Tinh gọn API Backend (Service Engine Consolidation)

Bản kế hoạch chi tiết kiểm tra, xóa bỏ các API dư thừa và hợp nhất toàn bộ luồng giao dịch tiền tệ về Hệ thống Engine 3 bước tiêu chuẩn (TMDS Standard Platform).

1. Danh sách Kiểm tra & Tinh gọn API (API Audit & Pruning List)

Tất cả các API giao dịch lẻ rải rác trước đây sẽ được xóa bỏ và chuyển hoàn toàn qua API Service Engine:

API Cũ (Cần Xóa / Tinh gọn) Trạng thái API Engine Thay thế Tiêu chuẩn Mã Service Catalog (`service_code`)
POST /v1/transactions/transfer ❌ XÓA DƯ THỪA POST /v1/transactions/request P2P_TRANSFER
POST /v1/wallets/topup ❌ XÓA DƯ THỪA POST /v1/transactions/request TOPUP_BANK
POST /v1/money-requests/:id/pay ❌ XÓA DƯ THỪA POST /v1/transactions/request MONEY_REQUEST
POST /v1/org/:id/topup ❌ XÓA DƯ THỪA POST /v1/transactions/request TOPUP_BANK
POST /v1/org/:id/transactions ❌ XÓA DƯ THỪA POST /v1/transactions/request ORG_DISBURSEMENT
POST /v1/transactions/request ⚡ ENGINE CORE Khởi tạo giao dịch theo Service Code Mọi `service_code` trong Catalog
POST /v1/transactions/confirm ⚡ ENGINE CORE Xác thực PIN / OTP & Hạch toán Action Pipeline Mọi `service_code` trong Catalog
POST /v1/transactions/verify ⚡ ENGINE CORE Xác thực 2FA cho giao dịch hạn mức lớn Mọi `service_code` trong Catalog

2. Quy trình Thực thi Task Chi tiết (Task Execution Breakdown)

Task 1: Dọn dẹp Router Backend (`d:\hpay\hpay-backend\internal\api\router.go`)

Xóa bỏ các endpoint thừa /transactions/transfer, /wallets/topup, /money-requests/:id/pay, /org/:id/transactions khỏi file router.go. Chỉ giữ lại bộ 3 API Engine /v1/transactions/request, confirm, verify.

Task 2: Bộ điều phối Service Engine Động (`d:\hpay\hpay-backend\internal\transfer\service.go`)

Bổ sung bộ Switch/Dispatcher đọc service_code từ DB PostgreSQL. Khi nhận yêu cầu giao dịch, Engine sẽ tự động kích hoạt Action Pipeline (GL Ledger Posting + Bank Gateway HTTP Call) tương ứng với Service đó.

Task 3: Cập nhật Mobile App Client (`d:\hpay\hpay-mobile`)

Chuyển đổi toàn bộ các màn hình Chuyển tiền, Xin tiền, Chi lương về gọi duy nhất useTransactionEngine().

Task 4: Đồng bộ Admin Ops Catalog (`d:\hpay\hpay-admin`)

Đảm bảo Admin Ops có thể bật/tắt và cấu hình Action Pipeline cho tất cả các Dịch vụ trong DB.
