📊 07 — Plan Kế hoạch Chuẩn hóa TanStack Table v8 & TanStack Query Pagination

Dựa trên việc tham chiếu trực tiếp source code hecci-develop, đây là bản kế hoạch chi tiết xây dựng module bảng phân trang (Server-Side Pagination, Sorting, Filtering) tối ưu nhất dùng chung cho hpay-admin và hpay-mobile.

1. Kiến trúc Tổng thể (Modular Table Architecture)

src/admin/src/
├── components/table/
│   ├── DataTable.tsx             # Component Render Bảng TanStack Table v8
│   ├── DataTablePagination.tsx   # Component Thanh phân trang (Trang 1,2.. | 10,20,50 hàng)
│   ├── DataTableToolbar.tsx      # Thanh công cụ Tìm kiếm + Lọc trạng thái + Date Range
│   └── DataTableRowActions.tsx   # Menu hành động trên từng hàng (View, Edit, Approve)
├── hooks/
│   ├── useTableQueryState.ts     # Hook quản lý State Phân trang (pageIndex, pageSize, search, sorting)
│   └── useServerTableQuery.ts    # Hook kết nối TanStack Query v5 fetch API có phân trang

2. Quy tắc Đồng bộ State (`useTableQueryState`)

  • Zero-Based vs One-Based: TanStack Table dùng pageIndex: 0 (zero-based), API Backend dùng page: 1 (one-based). Hook tự động chuyển đổi page = pageIndex + 1.
  • Auto-Reset Page: Khi người dùng gõ từ khóa tìm kiếm (Global Filter) hoặc chọn bộ lọc Filter mới, state pageIndex tự động reset về 0 (trang đầu tiên).
  • Manual Server-Side Flags: Khai báo manualPagination: true, manualSorting: true, manualFiltering: true để TanStack Table giao toàn bộ nhiệm vụ lọc & phân trang cho Backend SQL/Index.

3. Phân rã Tasks Triển khai (Detailed Execution Tasks)

Task 1: Tạo Module TanStack Table chuẩn trong `hpay-admin`

Cài đặt gói @tanstack/react-table và tạo bộ components DataTable.tsx, DataTablePagination.tsx, DataTableToolbar.tsx tại src/components/table/.

Task 2: Tạo Hooks Quản lý State & Query trong `hpay-admin`

Viết useTableQueryState.ts và useServerTableQuery.ts giúp tự động kết nối TanStack Query với API Backend có phân trang (chưa các thông số total, page, limit, total_pages).

Task 3: Cập nhật các Trang Admin Ops dùng Bảng Mới

Chuyển đổi các trang Audit Logs, KYC Queue, Approval Inbox, Service Catalog, Fraud Flags sang sử dụng DataTable mới.

Task 4: Phân trang Tối ưu cho Mobile (`hpay-mobile`)

Tạo hook usePaginatedList kết hợp TanStack Query useInfiniteQuery / useQuery với FlatList / FlashList hỗ trợ Pull-to-Refresh & Load More ở cuộn trang.
