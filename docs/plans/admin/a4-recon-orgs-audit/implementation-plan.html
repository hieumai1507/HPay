3. Recon page flow

sequenceDiagram
  Admin->>ReconPage: Chọn ngày → nhấn "Chạy"
  ReconPage->>API: POST /v1/admin/recon/run {date}
  API-->>ReconPage: {run_id} → polling
  ReconPage->>API: GET /v1/admin/recon/runs/:date (poll 2s)
  API-->>ReconPage: {matched, mismatched, rows, ai_summary, xlsx_key}
  ReconPage->>Admin: Hiển thị KPIs + AI summary + table
  Admin->>ReconPage: Nhấn "Xuất Excel"
  ReconPage->>Files: GET /v1/files/:xlsx_key
  Files-->>Browser: Download xlsx

4. Lưu ý Orgs & Policy

Policy snapshot: Cảnh báo nếu org có approval_requests với status pending — thay đổi policy chỉ áp dụng cho lệnh mới. Backend đã enforce điều này (E09 snapshot) nhưng UI cần hiển thị rõ số lệnh in-flight để admin cẩn thận.
Admin có thể dùng GET /v1/org với admin JWT (backend check audience=admin) vì cùng endpoint nhưng không bị lọc theo user_id — trả toàn bộ orgs. Nếu backend chưa hỗ trợ (cần kiểm tra), sẽ cần endpoint GET /v1/admin/orgs bổ sung.
