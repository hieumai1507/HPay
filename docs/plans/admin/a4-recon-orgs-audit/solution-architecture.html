2. Main flow A — chạy đối soát và xuất báo cáo

sequenceDiagram
  autonumber
  participant A as Ops
  participant P as ReconPage
  participant API as /v1/admin/recon
  participant F as /v1/files

  A->>P: Chọn ngày → "Chạy đối soát"
  P->>API: POST /v1/admin/recon/run {date}
  alt Ngày đã chạy rồi
    API-->>P: 409 ERR_RECON_ALREADY_RAN
    P->>API: GET /v1/admin/recon/runs/:date (hiển thị run cũ)
  else Chạy mới
    API-->>P: 201 {run_id} → poll 2s
    loop tới khi run xong
      P->>API: GET /v1/admin/recon/runs/:date
    end
    API-->>P: {run, items, ai_summary, report_url}
  end
  P-->>A: KPI + AI summary + bảng lệch
  A->>P: "Xuất Excel"
  P->>F: GET report_url (ký 5 phút)
  F-->>A: Download xlsx

3. Main flow B — cấu hình AI động (F11)

sequenceDiagram
  autonumber
  participant SA as Superadmin
  participant P as AISettingsPage
  participant API as /v1/admin/ai
  participant WF as Workflow step (kyc_scorer)

  SA->>P: Mở trang AI Settings
  P->>API: GET /v1/admin/ai/keys + GET /v1/admin/ai/settings (song song)
  API-->>P: keys (api_key masked) + settings per function
  SA->>P: Thêm key mới {name, provider, api_key}
  P->>API: POST /v1/admin/ai/keys
  API-->>P: 200 → invalidate ['ai','keys']
  SA->>P: Gán kyc_scoring → provider=openai, model=gpt-4o, key vừa tạo
  P->>API: PUT /v1/admin/ai/settings {function_name, provider, model_name, key_id}
  alt key_id trỏ vào key đã disable
    API-->>P: 400 ERR_KEY_INACTIVE → hiện lỗi cạnh select key
  else key không tồn tại
    API-->>P: 404 ERR_KEY_NOT_FOUND
  else OK
    API-->>P: 200 → toast
    Note over WF: Lần chạy KYC kế tiếp query settings
→ dùng ngay provider/model/key mới (không cache — thiết kế F11)
  end

4. State — vòng đời AI key (F11, nhìn từ admin)

stateDiagram-v2
  [*] --> active : POST /ai/keys (is_active=true)
  active --> inactive : PUT is_active=false (kill-switch)
  inactive --> active : PUT is_active=true
  note right of inactive
    Setting đang trỏ vào key inactive →
    workflow step trả ERR_AI_PROVIDER_UNAVAILABLE;
    UI phải cảnh báo ngay khi disable key đang được dùng
  end note

5. Data model delta

FE không đổi schema. Các bảng liên quan đã có từ backend: recon_runs, org_policies (snapshot — E09), audit_logs (immutable), và cặp ai_keys / ai_function_settings của F11 (ERD chi tiết trong f11 solution-architecture). Client cache keys: ['recon', date], ['orgs'], ['policies', orgId], ['ai','keys'], ['ai','settings'].
