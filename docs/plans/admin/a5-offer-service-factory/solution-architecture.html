A5 Offer Factory & Service Catalog — Solution Architecture

1. Executive Summary

Module A5 Offer Factory & Service Catalog cung cấp giao diện quản trị Admin Ops mở rộng cho hpay-admin. Giúp Admin chủ động tạo/sửa Danh mục Dịch vụ (Service Catalog), bật/tắt chế độ Maintenance mode bảo trì dịch vụ tức thì, và thiết lập các Gói Sản Phẩm (Offer Factory) phân hạng cho từng đối tượng người dùng (Khách hàng cá nhân KYC 1/2 vs Doanh nghiệp) kèm Ma trận hạn mức (Limit Matrix) và Ma trận xác thực (Auth Matrix: PIN vs OTP vs 2FA).

4. UI Component Layout Specifications

4.1 Service Catalog Page (`/services`)

  • Filter Bar: Tìm kiếm mã/tên service, dropdown Category, toggle "Chỉ hiển thị Dịch vụ Bảo trì".
  • Service Table: Cột Code, Name, Category, Priority, Switch Toggle Maintenance Mode (gọi API đổi trạng thái tức thì).
  • Form Modal: Thêm/Sửa thông tin Service.

4.2 Offer Factory Builder (`/offers` & `/offers/:id`)

  • Offer List Grid: Thẻ Offer hiển thị Role (Customer / Agent / Merchant / Biller), Level, trạng thái Active, số Dịch vụ được cấp phép.
  • Offer Builder Page (4 Steps Wizard / Tabs):
    1. Basic Info: Tên Offer, Role, Level (1-20), Status.
    2. Pocket Config: Hạn mức số dư ví chính (Min/Max Balance Limit), số ngân hàng liên kết tối đa.
    3. Authorized Services: Chọn danh sách Service được kích hoạt cho Offer này (Multi-select list với search).
    4. Service Component Config: Đối với từng Service được cấp phép:
      • Cấu hình Limit Matrix: Max per transaction, Daily limit, Monthly limit.
      • Cấu hình Authentication Matrix: Chọn PIN cho GD nhỏ (< 2M), OTP cho GD trung bình (2M-50M), 2FA (PIN+OTP) cho GD lớn (> 50M).
