A5 Offer Factory & Service Catalog — Implementation Plan

1. Scope & Deliverables

Bổ sung module Quản trị Gói sản phẩm và Dịch vụ tài chính cho hpay-admin:

  • Màn hình Service Catalog Manager (`/services`): Quản lý danh mục dịch vụ, bật/tắt chế độ bảo trì (Maintenance Mode).
  • Màn hình Offer Factory List (`/offers`): Danh sách gói sản phẩm theo phân hạng người dùng.
  • Màn hình Offer Detail Builder (`/offers/:id`): Trình cấu hình 4 bước (Basic info, Pocket Limits, Authorized Services, Service Components - Limit Matrix & Authentication Matrix).
