🏗 Implementation Plan — A1 Foundation hpay-admin

Phase khởi tạo toàn bộ codebase cho HPay Admin (hpay-admin) — ứng dụng SPA dành cho nhân viên vận hành nội bộ. Kết nối trực tiếp tới /v1/admin/* API (JWT audience=admin). Được xây dựng bằng Vite + React 18 + TypeScript + React Router v7, thiết kế theo mockups A1–A10.

1. Scope & non-goals

Ships trong A1

  • Scaffold Vite: khởi tạo project với TypeScript, React, TailwindCSS không dùng — dùng vanilla CSS tokens giống mobile, nhất quán thiết kế.
  • Design system: src/ui/tokens.css — CSS variables từ design spec (màu brand #0E90A3/#1ECBE1, sidebar dark #0B1220, v.v.), components: Button, Badge, Table, Sidebar, Topbar.
  • Layout shell: Sidebar (collapsible) + Topbar + main content area — dùng cho mọi page.
  • Routing: React Router v7 với lazy routes, protected route wrapper (RequireAdmin kiểm JWT).
  • Auth flow: Trang /login gọi POST /v1/admin/auth/login → lưu JWT vào sessionStorage (không persist qua tab — admin không nhớ session). Auto-refresh không cần: admin logout khi đóng tab.
  • API client: fetch wrapper typed (src/api/client.ts) tự động inject Authorization header từ store, map error codes (src/api/errors.ts). Gen types từ openapi.yaml qua npm run gen:api.
  • RBAC store: Zustand store useAdminStore lưu {token, role}, expose can() helper kiểm quyền (risk_officer, kyc_reviewer, superadmin).
  • Placeholder pages: Dashboard (số liệu tĩnh), KYC, Fraud, Workflow, Recon, Orgs, Audit — chỉ render shell, data thật sẽ fill ở A2-A4.
  • 404 / Error boundary toàn cục.

Non-goals A1

  • Data thật từ API (A2-A4 làm).
  • Charts/graphs thật (A2).
  • Dark mode toggle (sidebar đã dark, main area sáng — như mockup).
