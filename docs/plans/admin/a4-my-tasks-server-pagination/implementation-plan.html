Implementation Plan — My Tasks & Server-side Pagination

Feature slug: a4-my-tasks-server-pagination · Phase: B (post-audit) · Nguồn: doc 03 (A02, A04–A07) + doc 07. Đóng khoảng trống G5 (thiếu trang My Tasks) và G6/A02 (phân trang).

1. Hiện trạng đã khảo sát (không phải giả định)

Đính chính so với đợt rà soát đầu: báo cáo ban đầu mô tả admin “phân trang client-side”. Thực tế nặng hơn — không có model phân trang nào cả, nên điều khiển phân trang là vô hiệu. Ghi lại ở đây để plan phản ánh đúng sự thật.

2. Scope & Non-goals

Ships

  • G5 — My Tasks / Approval Inbox: route /tasks, bảng approval chờ duyệt, xem chi tiết, approve/reject kèm lý do, RBAC qua can(), xử lý 409 ERR_ALREADY_FINALIZED (A01).
  • G6/A02 — Phân trang server-side thật: hook trả {rows, total}; page truyền queryParams; bảng bật manualPagination: true + pageCount; DataTable nhận totalCount.

Non-goals (defer)

  • Chuyển React Router → TanStack Router (G8) — không chặn chức năng.
  • Async xlsx export polling (A06) và CRUD Orgs (G9) — tách plan riêng.
  • Bỏ dữ liệu demo fallback trong hooks — ghi nhận là nợ kỹ thuật, xử lý riêng.

4. API changes

Không đổi backend. Chỉ tiêu thụ đúng contract sẵn có:

GET /v1/admin/audit?page=1&limit=10&sort=created_at&order=desc
  → { logs: [...], total, page, limit, total_pages }

GET  /v1/admin/approvals?status=pending&page=1&limit=10
  → { approvals: [...], total, page, limit, total_pages }
POST /v1/admin/approvals/:id/decide   { action: "approve"|"reject", reason }
  → 409 ERR_ALREADY_FINALIZED khi người khác đã chốt trước (A01)

6. Rollout & risk

  • Rủi ro chính: đổi kiểu trả về của hook là breaking với mọi page đang dùng. Giảm thiểu: đổi từng hook một (audit làm mẫu trước), chạy tsc sau mỗi bước để compiler chỉ ra call site.
  • Backend chưa commit: phần pagination DTO của backend đang nằm trong working tree chưa commit (không phải việc của plan này). FE phụ thuộc nó — nếu backend revert, các page sẽ nhận total undefined; hook phải fallback total = rows.length để không vỡ.
  • Không có backfill/migration — thuần frontend, rollback = revert commit.
