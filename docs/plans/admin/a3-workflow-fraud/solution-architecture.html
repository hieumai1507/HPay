🔀 Solution Architecture — A3 Workflow Monitor & Fraud hpay-admin

Kiến trúc cho 2 màn hình vận hành realtime-ish: Workflow Monitor (observability của engine F4) và Fraud Monitor (xử lý flags F9). Nguyên tắc xuyên suốt: FE không tự quyết logic nghiệp vụ — action khả dụng đọc từ API, hệ quả (khóa/hủy/reversal) do backend thực hiện qua đúng engine.

2. Main flow — resolve 1 fraud flag (kèm nhánh lỗi)

sequenceDiagram
  autonumber
  participant O as Risk Officer
  participant P as FraudPage
  participant D as ResolveDialog
  participant API as /v1/admin/fraud-flags
  participant BE as Backend (engine/approval)

  O->>P: Mở queue open (auto-refresh 30s, SLA > 30' tô đỏ)
  P->>API: GET /v1/admin/fraud-flags?status=open
  API-->>P: [{id, rule_code, score, reasons, txn, created_at}]
  O->>D: "Confirm fraud" → mở dialog hệ quả
  O->>D: Chọn 1 trong 3: lock+cancel / lock+reversal / mark-only, nhập reason ≥ 10 ký tự
  D->>API: POST /v1/admin/fraud-flags/:id/resolve {action, reason}
  alt Flag đã được xử lý ở nơi khác (A01/A05)
    API-->>D: 409 + state mới
    D-->>O: Toast + cập nhật row tại chỗ
  else Txn completed → cần reversal
    API->>BE: Tạo approval request reversal (không ghi thẳng ledger)
    BE-->>API: 201
    API-->>D: 200 {result: "reversal_pending_approval"}
    D-->>O: Toast "chờ duyệt ở My Tasks"
  else Xử lý trực tiếp OK
    API-->>D: 200
    D->>P: invalidate → row cập nhật
  end

3. State — action hợp lệ theo trạng thái workflow instance

stateDiagram-v2
  [*] --> running
  running --> waiting_approval : PauseHook (human gate)
  running --> failed : step lỗi terminal
  waiting_approval --> running : approve → resume
  failed --> running : Retry step (action)
  failed --> compensating : Force fail + compensate (action, cần reason)
  compensating --> compensated
  running --> completed

4. Data model delta

Không đổi schema. Client state: query keys ['workflow', filters], ['workflow', id] (refetch 10s), ['fraud', status] (refetch 30s). SLA timer là derived state (created_at → now, tick 60s), không lưu.

5. Decisions & trade-offs
