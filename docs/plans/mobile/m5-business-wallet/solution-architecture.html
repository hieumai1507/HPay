2. State Management — Zustand store

Để lưu trữ trạng thái của doanh nghiệp đang hoạt động độc lập với session đăng nhập, chúng ta thiết lập useOrgStore:

interface ActiveOrg {
  orgId: string;
  name: string;
  role: 'admin' | 'maker' | 'checker';
  checkerLevel: number;
  walletId: string;
  balance: bigint;
}

interface OrgState {
  activeOrg: ActiveOrg | null;
  switchOrg: (org: ActiveOrg) => void;
  exitOrg: () => void;
  updateBalance: (balance: bigint) => void;
}

3. Sequence Diagram — Checker Approval execution

sequenceDiagram
  autonumber
  actor Checker
  participant Detail as Màn hình chi tiết duyệt
  participant API as Backend Gateway
  participant OTP as Modal Nhập OTP
  
  Checker->>Detail: Nhấn nút "Phê duyệt"
  Detail->>API: POST /v1/org/approvals/{id}/challenge (OTP request)
  API-->>Detail: 200 OK (trả về status: "otp_sent" + otp_dev trong dev)
  Detail->>OTP: Mở modal yêu cầu nhập OTP
  Checker->>OTP: Nhập 6 chữ số
  OTP->>API: POST /v1/org/approvals/{id}/decide {action: "approve", otp}
  API-->>OTP: 200 OK (Duyệt thành công, workflow resume)
  OTP-->>Detail: Đóng modal, hiển thị thông báo thành công
  Detail->>Detail: Điều hướng về màn danh sách duyệt
