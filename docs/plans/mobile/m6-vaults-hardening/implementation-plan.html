2. Scope & Non-goals

Ships

  • Vaults: màn danh sách (hero tổng để dành, VaultCard) + màn chi tiết (progress theo mục tiêu, nạp/rút, lịch sử), nối vào API mới qua TanStack Query.
  • M11: gọi loadDraft khi vào luồng KYC và prefill 2 màn capture.
  • M07 bổ sung: chặn chụp màn hình ở các màn nhạy cảm (số dư, OTP, ảnh KYC).

Non-goals

  • Round-up toggle — backend chưa có step ROUND_UP; UI sẽ không hiển thị công tắc chết.
  • M08 — đã xong, không đụng.
  • SplitAvatarStack, tách màn maker-status/checker-result — polish, tách plan riêng.

4. API dùng tới

GET  /v1/vaults                                  → danh sách hũ
POST /v1/vaults {label, target_amount?}          → tạo hũ
POST /v1/transactions/request                    → nạp/rút
  { service_code:"VAULT_SAVINGS", amount,
    extra_params:{ vault_id, direction:"deposit"|"withdraw" } }
POST /v1/transactions/confirm { transaction_id, pin }

Tiền vẫn đi qua đúng bộ 3 API engine — mobile không gọi endpoint tiền riêng nào cho vault.

6. Rollout & risk

  • Phụ thuộc backend: T1–T4 không chạy được cho tới khi vaults-engine merge. Làm T5/T6 trước để không bị chặn.
  • expo-screen-capture cần native build — không hoạt động trên Expo Go. Phải kiểm trên dev build, và bọc try/catch để Expo Go không crash.
  • Không hiển thị RoundUpToggle khi backend chưa có — thà thiếu còn hơn có công tắc không làm gì.
  • Rollback: thuần UI + 1 package, revert commit là xong.

7. Execution checklist

  1. T5, T6 (độc lập backend) → jest xanh.
  2. Chờ vaults-engine merge → npm run gen:api sinh lại types.
  3. T1 → T2/T3 (gen-screen) → T4.
  4. T7 tests → npx tsc --noEmit + jest.
  5. detect_changes() trước commit; cập nhật plan nếu code lệch.
