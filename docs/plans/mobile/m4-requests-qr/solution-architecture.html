2. Data flow — Pay request (tái dùng hạ tầng transfer)

sequenceDiagram
  participant UI as Pay screen
  participant Q as TanStack Query
  participant API as api client (interceptors)
  participant BE as backend
  UI->>UI: vào màn → sinh Idempotency-Key (1 lần)
  UI->>Q: mutate pay(id)
  Q->>API: POST /v1/money-requests/{id}/pay (Idempotency-Key)
  API->>BE: + Authorization, X-Device-Id, X-Request-Id
  alt 202 async
    BE-->>API: ref_code
    UI->>UI: Processing — TransactionWatcher poll 1s→2s→4s
  else ERR_REQUEST_EXPIRED / _CANCELLED / _ALREADY_PAID
    UI->>UI: dừng an toàn, toast trạng thái mới, invalidate inbox
  end
Nguyên tắc: pay request = transfer có nguồn gốc request. Không nhân bản flow — pay.tsx tái dùng component confirm/processing của transfer với dữ liệu prefill khóa cứng (không cho sửa số tiền), vẫn qua PIN theo auth matrix doc 02 (biometric chỉ mở app).

3. Split — tiền không đi qua float

src/lib/split.ts: splitEven(total: bigint, n: number): bigint[] — chia phần nguyên, dư rải largest-remainder (+1 minor unit từ đầu danh sách). Custom mode: validate sum(parts) === total bằng BigInt. Preview client chỉ để hiển thị — server tính lại và là nguồn chân lý (split_group_id từ response 201).
