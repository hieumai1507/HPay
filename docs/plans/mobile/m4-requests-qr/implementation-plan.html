📋 Implementation Plan — M4 Request Money · Split Bill · QR · Account mobile

Phase xây dựng Request Money (xin tiền), Split Bill (chia hóa đơn), QR nhận tiền (gated backend), màn Account thật, kèm rebrand màu chủ đạo #1ecbe1 cho design mobile/admin và trả nợ M12 (FlashList).

Dependency backend: money-requests API đã có đầy đủ trong openapi.yaml (create/split/inbox/sent/detail/pay/decline/cancel). Riêng QR cần phase m4-api-support phía backend (xem §6).

1. Scope & non-goals

Ships

  • T0 Rebrand #1ecbe1: chỉ đổi các file design của sản phẩm — src/mobile/src/ui/tokens.ts, bảng token trong docs/design/ui-design-spec.html, design/mockups/mp-base.css + biến màu trong các mockup. KHÔNG đổi giao diện chrome của các trang docs khác. #1ECBE1 làm accent (hero, gradient, icon active); bậc đậm #0E90A3/#0B7181 cho button/link/pressed để đạt contrast AA với chữ trắng.
  • Request Money (mockup 25–27): tạo yêu cầu, Inbox 2 tab "Cần tôi trả / Tôi đã gửi", chi tiết, Pay (prefill confirm → tái dùng flow confirm/processing của transfer), Decline (kèm lý do), Cancel yêu cầu mình gửi.
  • Split Bill (mockup 28–29): chia đều / tùy chỉnh — preview bằng BigInt largest-remainder (không float), server là nguồn chân lý; màn theo dõi split group.
  • Account screen thật: profile từ /v1/users/me, trạng thái KYC + hạn mức, toggle biometric, mặc định ẩn số dư, logout. Sửa bug text "coming in M3".
  • Nợ M3 — edge M12: history chuyển SectionList → FlashList, giữ nguyên cursor pagination.
  • QR nhận tiền (mockup 16) — GATED chỉ code sau khi backend m4-api-support merge + npm run gen:api.

Non-goals

  • Vaults / round-up (mockup 30–31) — chưa có contract backend, backlog.
  • Nút "Nhắc nợ" (mockup 29) — chưa có endpoint remind, mobile ẩn nút, backlog.
  • Business maker/checker (M5); push notification thật.

5. Rebrand #1ecbe1 & giảm "AI look"

Brand scale: 50 #E6FAFD · 100 #C9F4FA · 300 #64DDEC · 400 #1ECBE1 (accent gốc) · 600 #0E90A3 (primary button/link — AA trên trắng) · 700 #0B7181 (pressed) · 900 #073F48. #1ecbe1 quá sáng làm nền nút chữ trắng (contrast ~1.9:1) nên giữ làm màu nhận diện; bậc 600/700 cho interactive.
Giảm "AI look": bỏ emoji làm icon hệ thống (dùng icon set nhất quán), giảm gradient mặc định, tăng khoảng trắng, số dùng tabular-nums. Áp dần vào các màn M4 chạm tới; màn cũ sửa ở polish pass M5.
Phạm vi: chỉ đổi file design sản phẩm (tokens.ts, ui-design-spec, mockups). Không đổi style các trang docs khác của hpay-docs.
