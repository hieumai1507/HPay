2. Main flow — một step auto trọn vòng đời (kèm nhánh lỗi)

sequenceDiagram
  autonumber
  participant EN as engine
  participant OB as outbox→relay
  participant ST as wf:steps:H
  participant W as step worker
  participant DB as PostgreSQL
  participant EV as wf:events
  EN->>OB: step.start {inst, step, attempt}
  OB->>ST: XADD
  ST->>W: XREADGROUP
  W->>DB: step_executions đã có (inst,step,attempt)?
  alt đã completed (redelivery — E04/E06)
    W->>OB: phát lại result cũ (không side-effect)
  else chưa
    W->>W: handler.Execute(ctx, timeout_ms)
    alt ok
      W->>DB: tx: side-effects + step_execution(completed) + outbox(result ok)
    else RetryableError
      W->>DB: step_execution(failed, attempt) + outbox(result failed retryable)
    else terminal
      W->>DB: step_execution(failed) + outbox(result failed terminal)
    end
  end
  W->>ST: XACK
  EV->>EN: result event
  EN->>DB: SELECT instance FOR UPDATE\nguard: status=running AND current_step khớp
  alt ok → còn step
    EN->>OB: step.start(step kế, attempt=1)
  else ok → hết step
    EN->>DB: instance=completed
  else failed retryable & attempt < retry
    EN->>OB: step.start(cùng step, attempt+1)\navailable_at = now + 2^attempt s (trần 60s)
  else failed terminal
    EN->>DB: theo on_failure: failed / compensating / manual\n+ FailTransactionGuarded nếu có txn
  end

3. State — workflow instance (F4 kích hoạt đầy đủ trừ resume)

stateDiagram-v2
  [*] --> running : Start()
  running --> running : step completed → advance / retry
  running --> waiting_approval : gặp step human_approval\n(resume ở F6)
  running --> completed : hết step
  running --> failed : on_failure=fail / manual
  running --> compensating : on_failure=compensate
  compensating --> compensated : mọi step cần đảo đã đảo\n(F4: framework, F5: thực thi tiền)
  running --> recovering : sweep lease (E20)
  recovering --> running : re-emit step hiện tại
  completed --> [*]
  failed --> [*]
  compensated --> [*]
