3. Schema changes

000011: ALTER TABLE outbox ADD COLUMN available_at TIMESTAMPTZ NOT NULL DEFAULT now() + thay index unpublished thành (available_at, id) WHERE published_at IS NULL. Retry backoff = ghi outbox row với available_at tương lai (2^attempt giây, trần 60s) — không cần scheduler ngoài.

4. API changes

Không có endpoint mới (engine là hạ tầng nội bộ; P2P API đến ở F5). --role=worker giờ chạy thật: relay + consumers + recovery.

6. Rollout & risk

  • Engine generic — không đụng luồng topup sync F3. P2P chỉ bật khi F5 thêm definition + handlers.
  • Compensation ở F4 là framework (instance chuyển compensating→compensated khi không có step nào cần đảo); thực thi đảo tiền đến cùng wallet handler F5 — ghi rõ để không ngộ nhận đã xong.
  • Worker và API chạy chung 1 process ở dev (--role=all); tách process là quyết định deploy, không phải code.
