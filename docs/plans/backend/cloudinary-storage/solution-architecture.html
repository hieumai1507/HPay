2. Main flow — Luồng nộp ảnh & Xem ảnh

A. Luồng nộp KYC (Put)

sequenceDiagram
  autonumber
  actor User as Mobile App
  participant API as internal/kyc
  participant ST as storage.Cloudinary
  participant CLD as Cloudinary REST API
  
  User->>API: Nộp hồ sơ KYC (2 ảnh)
  API->>ST: Put(ctx, "req-1/id_card.jpg", bytes)
  ST->>ST: Sinh timestamp & chữ ký SHA-1 dùng API Secret
  ST->>CLD: Multipart POST (file + signature + api_key)
  CLD-->>ST: 200 OK (Upload thành công)
  ST-->>API: Trả về nil error
  API-->>User: 202 Accepted (Giao dịch đang xử lý)

B. Luồng admin xem ảnh (Get)

sequenceDiagram
  autonumber
  actor Admin as Admin SPA
  participant API as internal/api (ServeFile)
  participant ST as storage.Cloudinary
  participant CLD as Cloudinary CDN
  
  Admin->>API: GET /v1/files/kyc/req-1/id_card.jpg?exp=...&sig=... (HMAC URL)
  API->>API: Xác thực chữ ký HMAC & thời gian hết hạn (5 phút)
  API->>ST: Get(ctx, "req-1/id_card.jpg")
  ST->>CLD: HTTP GET https://res.cloudinary.com/cloud/image/upload/req-1/id_card.jpg
  CLD-->>ST: Trả về image binary data
  ST-->>API: Trả về []byte
  API-->>Admin: Trả về image binary data với Content-Type tương ứng

3. Decisions & trade-offs

Quyết địnhPhương án thay thếLý do & Ưu điểm
Proxy ảnh thông qua Backend ở hàm Get() Trả thẳng URL trực tiếp của Cloudinary cho client hiển thị. - **Bảo mật và Quyền riêng tư:** Ảnh KYC chứa thông tin nhạy cảm của người dùng (PII). Nếu dùng link trực tiếp của Cloudinary, người ngoài có thể đoán URL hoặc chia sẻ link vĩnh viễn. Proxy qua backend giúp duy trì cơ chế bảo vệ HMAC Signed URL 5 phút.
- **Tính độc lập:** Client không cần biết ảnh đang nằm trên Cloudinary hay ổ đĩa cục bộ, đảm bảo tính đóng gói của hệ thống.
Sử dụng HTTP Client thuần của Go thay vì cài SDK Cloudinary chính thức Chạy go get github.com/cloudinary/cloudinary-go/v2 - **Tối giản dependencies:** Giảm kích thước build của ứng dụng, tránh rủi ro bảo mật từ các package con bắc cầu.
- **Độ tin cậy cao:** Các API của Cloudinary rất ổn định, việc gọi REST API qua multipart form tốn rất ít dòng code và dễ dàng debug/mock kiểm thử.

4. Invariants touched (Quy chuẩn bảo mật & Fintech)

  • Bảo vệ PII (Thông tin cá nhân nhạy cảm): Không công khai URL Cloudinary trực tiếp ra bên ngoài. Toàn bộ ảnh xem phải qua kiểm tra chữ ký HMAC an toàn trong 5 phút.
  • Độc lập hạ tầng: Khóa lưu trữ (key) trong DB luôn là khóa tương đối (ví dụ: req-123/selfie.jpg) thay vì URL tuyệt đối, giúp việc di chuyển (migration) dữ liệu giữa các Cloud provider sau này trở nên cực kỳ đơn giản mà không cần chạy migration SQL.
