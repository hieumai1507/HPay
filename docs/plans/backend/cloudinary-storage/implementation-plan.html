Cloudinary Cloud Storage — Implementation Plan

1. Scope & non-goals

Điểm mấu chốt: Thay vì lưu trữ tệp tin KYC và báo cáo Excel trực tiếp vào hệ thống file local ở server (thư mục ./data/kyc), hệ thống sẽ hỗ trợ cấu hình chuyển tiếp lưu trữ lên Cloudinary. Toàn bộ logic được trừu tượng hóa qua interface storage.Store sẵn có, giúp các service nghiệp vụ KYC và đối soát không cần thay đổi code.
Những gì sẽ triển khai (Ships)Không làm ở phạm vi này (Non-goals)
- Thêm driver Cloudinary thực thi interface storage.Store.
- Triển khai cơ chế chữ ký xác thực SHA-1 (Signed Upload) tăng tính bảo mật cho Cloudinary API.
- Hỗ trợ đổi loại tài nguyên (resource_type): tự động nhận dạng file ảnh KYC thành image và báo cáo đối soát dạng Excel thành raw.
- Hỗ trợ biến môi trường để cấu hình và bật tắt driver: STORAGE_PROVIDER=local|cloudinary.
- Tải tệp trung gian (Get) thông qua HTTP client để ServeFile ở backend hoạt động liền mạch mà không làm lộ trực tiếp đường dẫn lưu trữ trên Cloudinary. 		- Không thay đổi hành vi nghiệp vụ của các service KYC, Đối soát hay Admin handler.
- Không lưu URL tuyệt đối của Cloudinary vào cơ sở dữ liệu (Database vẫn lưu key tương đối dạng {request_id}/id_card.jpg để dễ dàng chuyển đổi nhà cung cấp lưu trữ).
- Không tích hợp các nhà cung cấp khác (AWS S3, MinIO) trong đợt này.

3. Schema changes

Không có thay đổi cơ sở dữ liệu. Bảng kyc_requests và reconciliation_reports vẫn giữ nguyên cấu trúc lưu trữ khóa tệp tương đối dạng string.

4. API changes

Không có sự thay đổi nào đối với cấu trúc API đầu ra (OpenAPI Spec). Mọi Endpoint của người dùng và admin hoạt động hoàn toàn giống như cũ.

5. Test plan

NhómMô tả kiểm thử
Unit Test (Mock)Kiểm tra chữ ký SHA-1 khớp thuật toán Cloudinary; kiểm tra Multipart body có chứa đúng các field cần thiết; kiểm tra đổi loại resource thành raw khi file là .xlsx.
E2E TestĐảm bảo luồng nộp ảnh KYC và xuất báo cáo đối soát vẫn hoàn thành 100% khi cấu hình chuyển đổi giữa local và cloudinary.

6. Rollout & risk

  • Rủi ro sai thông tin xác thực: Khắc phục bằng việc kiểm tra fail-fast ngay khi khởi động ứng dụng (nếu chọn cloudinary nhưng thiếu credentials thì backend sẽ tự ngắt ngay).
  • Khả năng fallback: Khi cần tắt Cloudinary hoặc bảo trì, chỉ cần cấu hình STORAGE_PROVIDER=local trong file cấu hình .env mà không phải cài đặt lại source code.
