Solution Architecture — Workflow Instances Filters

Song hành với implementation-plan.html. Cùng khuôn mẫu listing.Filter đã dùng ở audit log / fraud flags, cộng thêm 3 tham số riêng của trang này (status/definition/stuck_only) vì UI đã có sẵn 3 control cho đúng 3 chiều đó.

1. Context

flowchart LR
  UI["WorkflowPage.tsx\nstatus/definition/stuckOnly"] --> HOOK["useWorkflowInstances"]
  HOOK -->|"GET /v1/admin/workflows?status=&definition=&stuck_only="| H["AdminHandler.ListWorkflows"]
  H -->|"map waiting→waiting_approval"| SVC["product.Service.ListWorkflowInstances"]
  SVC --> SQL[("workflow_instances ⋈ workflow_definitions ⋈ transactions\nstatus / d.name ILIKE / stuck_only / ref_code / created_at")]

2. Main flow

sequenceDiagram
  participant UI as WorkflowPage
  participant API as GET /v1/admin/workflows
  participant SVC as product.Service
  participant DB as workflow_instances

  UI->>API: status=waiting&definition=p2p_transfer&stuck_only=false
  API->>API: status "waiting" → "waiting_approval"
  API->>SVC: ListWorkflowInstances(f, status, definition, stuckOnly)
  SVC->>DB: WHERE (status IS NULL OR i.status::text = status)\n  AND (definition IS NULL OR d.name ILIKE %definition%)\n  AND (NOT stuck_only OR (i.status='running' AND age > 5m))
  DB-->>SVC: rows + count
  SVC-->>API: rows, total
  API-->>UI: {workflows, total, page, limit, total_pages}

3. State — stuck_only là hệ quả của status + tuổi, không phải cột riêng

stateDiagram-v2
  [*] --> CheckStatus
  CheckStatus --> Excluded: stuck_only=true AND status != running
  CheckStatus --> CheckAge: stuck_only=true AND status = running
  CheckAge --> Excluded: created_at >= now()-5m
  CheckAge --> Included: created_at < now()-5m
  CheckStatus --> Included: stuck_only=false
  Excluded --> [*]
  Included --> [*]

4. Data model delta

Không có bảng/cột mới — chỉ đổi câu truy vấn trên schema hiện có.

5. Decisions & trade-offs

Quyết địnhPhương án khácVì sao
Map "waiting"→"waiting_approval" ở tầng API, không đổi enum DBĐổi UI hiển thị đúng "waiting_approval"Giữ nhãn ngắn gọn cho operator; enum DB là chi tiết triển khai, không nên rò ra UI
stuck_only tính bằng created_at < now() - interval '5 minutes' trong SQLTính ở Go rồi lọc in-memoryCùng logic với UI đang tính (ageMin > 5), nhưng phải chạy trên toàn bảng để phân trang đúng — chuyển hẳn xuống SQL
definition lọc bằng ILIKE trên d.nameĐổi dropdown sang gửi definition_id (UUID) chính xác tuyệt đốiGiữ đúng hành vi hiện tại của dropdown (so theo tên hiển thị), tránh phải đổi UI/mapping thêm

6. Invariants touched

Không invariant tài chính nào — đường đọc thuần cho màn giám sát vận hành (Ops Monitor), không post ledger, không đổi trạng thái workflow.
