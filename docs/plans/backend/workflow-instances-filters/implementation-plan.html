Implementation Plan — Workflow Instances Filters

Feature slug: workflow-instances-filters · Cùng dạng nợ kỹ thuật như audit-log-search: UI Workflow Monitor (WorkflowPage.tsx) đã có sẵn 3 bộ lọc (status/definition/stuck>5m) nhưng comment tự ghi rõ "API has no such filters yet" — lọc client-side trên đúng 1 trang dữ liệu, không phải trên toàn bộ bảng.

2. Scope & Non-goals

Ships

  • Backend: ListWorkflowInstances/CountWorkflowInstances lọc theo status (map "waiting"→"waiting_approval"), definition (tên definition, ILIKE), stuck_only (status=running AND tuổi > 5 phút), cộng thêm name (khớp ref_code) + from/to + order đã có sẵn qua listing.Filter (chi phí bằng 0, đồng bộ với mọi list khác).
  • Admin: useWorkflowInstances gửi status/definition/stuck_only lên server, bỏ filterInstances() client-side và cảnh báo "clientFiltered" trong comment.

Non-goals (defer)

  • Thêm ô search tự do (ref_code) vào UI — name được hỗ trợ ở backend cho đồng bộ, nhưng không có yêu cầu thêm input mới trên trang này.
  • Đổi cơ chế auto-refresh 10s hiện có.

4. Schema changes

Không có migration — bảng workflow_instances/workflow_definitions đã đủ cột, chỉ đổi câu query.

5. API changes

GET /v1/admin/workflows?status=waiting&definition=p2p_transfer&stuck_only=true&name=MP1A2B&from=2026-07-01&page=1&limit=10

status chấp nhận cả nhãn ngắn waiting (map sang waiting_approval) lẫn giá trị enum thật, để không phá tương thích nếu ai đó gọi trực tiếp API bằng giá trị DB.
