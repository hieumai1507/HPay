6. Rollout & risk

  • Callback endpoint dưới /internal/ — không nằm trong nhóm route user; nếu deploy thật phải chặn ở reverse proxy. Secret qua env, không hardcode.
  • k6 kết quả phụ thuộc máy — thresholds đặt theo NFR; nếu laptop không đạt 100 TPS, ghi số thật vào README kèm phân tích bottleneck, không sửa threshold cho "xanh".
  • trivy có thể fail vì base image cũ — xử lý bằng bump image/deps, là mục đích của phase này.
  • Seeder chạy trên DB dev — idempotent bằng fixed UUID nên re-run an toàn; không bao giờ chạy trên DB có dữ liệu thật (guard: từ chối chạy nếu ENV=production).
  • Merge nửa chừng không phá gì: mọi task độc lập với runtime hiện có trừ T1 (endpoint mới, additive).
