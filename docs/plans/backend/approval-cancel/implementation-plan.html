Implementation Plan — Maker Cancels a Pending Approval

Feature slug: approval-cancel · Nguồn: mockup 03-business.html frame 19 — nút "Hủy lệnh" đã có UI trên màn order-status.tsx (hpay-mobile) nhưng chỉ là placeholder Alert, chưa có API đứng sau. Đi kèm feature mobile approval-result-screens (frame 22/23) — không phụ thuộc backend, chỉ tiêu thụ dữ liệu đã có.

Cập nhật sau khi triển khai: down migration ban đầu cố ý fail luôn (irreversible-by-design) — nhưng vi phạm gate CI E18: migrate up→down→up chạy trên DB rỗng, nơi việc recreate enum type hoàn toàn an toàn (không có row nào ở trạng thái cancelled). Đã sửa: down migration giờ có điều kiện — chỉ RAISE EXCEPTION nếu thực sự có row cancelled tồn tại (bảo vệ dữ liệu thật), còn lại (DB rỗng/CI) thì recreate type qua rename→create→alter→drop và chạy sạch. Đã verify thủ công: chặn đúng khi có 2 row cancelled thật, chạy sạch sau khi dọn — xem db/migrations/000011_approval_cancelled_status.down.sql.

2. Scope & Non-goals

Ships

  • Migration thêm giá trị enum cancelled vào approval_status.
  • Service.Cancel(ctx, makerID, requestID) error — chỉ created_by (maker) mới hủy được, chỉ khi status=pending; tái dùng finalize() nguyên vẹn.
  • POST /v1/org/approvals/{id}/cancel.

Non-goals (defer)

  • Checker/admin hủy hộ lệnh của người khác — chỉ maker tự hủy lệnh của chính mình, đúng theo mockup.
  • Hoàn phí/hoàn tiền — CreateDisbursement chưa trừ tiền trước khi duyệt (giữ nguyên hành vi cũ của reject), nên không có gì để hoàn.

4. Schema changes

1 migration: thêm giá trị cancelled vào enum approval_status (xem T1).

5. API changes

POST /v1/org/approvals/{id}/cancel
→ 200 {status: "cancelled"}
→ 404 ERR_APPROVAL_NOT_FOUND — không phải maker của lệnh này, hoặc lệnh không tồn tại
→ 409 ERR_ALREADY_FINALIZED — lệnh không còn ở trạng thái pending

7. Rollout & risk

Rủi ro thấp — thêm 1 enum value (forward-only, an toàn vì Postgres append-only cho ADD VALUE) và 1 hành động mới tái dùng nguyên finalize() đã có test bao phủ (reject/expire cùng đường). Không đổi hành vi các luồng hiện có.
