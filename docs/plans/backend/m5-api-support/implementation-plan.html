M5 API Support — Implementation Plan

1. Scope

Bổ sung API hỗ trợ lấy danh sách các doanh nghiệp mà người dùng hiện tại là thành viên (đáp ứng màn hình chuyển ví cá nhân <> doanh nghiệp trên Mobile).

2. Task Breakdown

#TaskFiles chínhSizeDepends
T1 Cập nhật openapi.yaml thêm phương thức get cho /v1/org api/openapi.yaml S —
T2 Thêm SQL query ListUserOrganizations trong org.sql và chạy make sqlc internal/store/queries/org.sql S —
T3 Cập nhật internal/org/service.go để thêm hàm lấy danh sách doanh nghiệp internal/org/service.go S T2
T4 Thêm handler ListMyOrgs trong org_handler.go và map route trong router.go internal/api/org_handler.go, internal/api/router.go S T3
T5 Viết kiểm thử tích hợp (Integration Test) cho API mới test/integration/org_test.go (hoặc qr_test.go) M T4

3. API Specification

Chi tiết route được thêm:

Headers: Authorization: Bearer

{

  ]
}
