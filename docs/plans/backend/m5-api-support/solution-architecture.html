3. Database Query design

Phương thức ListUserOrganizations thực hiện ghép 3 bảng để lấy đầy đủ siêu dữ liệu cần thiết cho client trong một lần gọi:

-- name: ListUserOrganizations :many
SELECT 
    o.id AS org_id, 
    o.name, 
    o.status, 
    m.role, 
    COALESCE(m.checker_level, 0)::smallint AS checker_level, 
    w.id AS wallet_id, 
    w.balance
FROM org_members m
JOIN organizations o ON o.id = m.org_id
LEFT JOIN wallets w ON w.owner_type = 'organization' AND w.owner_id = o.id
WHERE m.user_id = $1 AND o.status = 'active';
