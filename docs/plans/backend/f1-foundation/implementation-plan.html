6. Rollout & risk

  • Repo mới, chưa có user — rollback = revert commit.
  • Rủi ro chính: schema chốt sớm sai → đã mitigate bằng review docs 2 vòng; thay đổi sau đi qua gen-migration bình thường.
  • Sandbox không có Go toolchain: code được verify bằng review + CI là chốt chặn compile thật. Commit đầu cần chạy go mod tidy trên máy dev để sinh go.sum.
