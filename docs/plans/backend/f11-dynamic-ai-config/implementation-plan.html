F11 Dynamic AI Config — Implementation Plan

1. Scope & non-goals

Điểm mấu chốt: Chuyển cấu hình AI (LLM Provider, Models, API Keys) từ tĩnh ở file .env sang quản lý động ở Database. Cho phép thay thế/đổi Key qua API của Admin, kích hoạt/hủy kích hoạt Key khẩn cấp khi gặp lỗi, và ánh xạ các tính năng AI khác nhau (KYC scoring, Fraud advising) tới các model/provider khác nhau (Anthropic Claude, OpenAI GPT) để tối ưu chi phí/hiệu năng. UI quản trị của tính năng này thuộc phase A4 phía admin — xem src/admin/docs/plans/a4-recon-orgs-audit/ (task T6/T6b + mục 3–4 solution-architecture).
Những gì sẽ triển khai (Ships)Không làm ở phạm vi này (Non-goals)
- **Bảng Database mới**: ai_keys (quản lý pool keys, trạng thái active/inactive) và ai_function_settings (bản đồ ánh xạ chức năng -> model + key).
- **Hỗ trợ đa nhà cung cấp**: Tích hợp các client API thuần cho cả Anthropic Claude (Messages API) và OpenAI GPT (Chat Completions API) trong KYC Scorer và Fraud Advisor.
- **Cơ chế fallback**: Tự động chuyển về trạng thái Mock hoặc báo lỗi phù hợp khi nhà cung cấp hoặc API key của chức năng đó bị vô hiệu hóa (inactive).
- **Hệ thống API quản trị**: Cung cấp các API Admin bảo mật để quản lý Key (Thêm, Sửa trạng thái, Cập nhật) và cài đặt tính năng (Cấu hình Model & Provider cho từng chức năng). 		- Giao diện Admin SPA hoàn chỉnh (chỉ tập trung cung cấp API đầu cuối phía Backend).
- Tích hợp thêm các provider ngoài Anthropic và OpenAI (ví dụ Gemini, DeepSeek) trong phase này.

3. Schema changes

Thêm hai bảng mới trong Migration 000015_create_ai_configs.up.sql:

```sql CREATE TABLE ai_keys ( id UUID PRIMARY KEY DEFAULT gen_random_uuid(), name VARCHAR(100) NOT NULL, provider VARCHAR(50) NOT NULL, -- 'anthropic' | 'openai' api_key VARCHAR(255) NOT NULL, -- Encrypted/encrypted-at-rest trong tương lai is_active BOOLEAN NOT NULL DEFAULT TRUE, created_at TIMESTAMP NOT NULL DEFAULT NOW(), updated_at TIMESTAMP NOT NULL DEFAULT NOW() ); CREATE TABLE ai_function_settings ( function_name VARCHAR(100) PRIMARY KEY, -- 'kyc_scoring' | 'fraud_advising' provider VARCHAR(50) NOT NULL, -- 'anthropic' | 'openai' | 'mock' model_name VARCHAR(100) NOT NULL, -- e.g. 'claude-3-5-sonnet', 'gpt-4o' key_id UUID REFERENCES ai_keys(id) ON DELETE SET NULL, updated_at TIMESTAMP NOT NULL DEFAULT NOW() ); ```

6. Rollout & risk

  • Hủy kích hoạt đột ngột: Nếu admin vô hiệu hóa tất cả các key hoạt động của kyc_scoring, hệ thống sẽ rơi vào trạng thái ngừng hỗ trợ duyệt tự động (fallback về duyệt thủ công hoặc trả lỗi kiểm duyệt). Cần hiển thị cảnh báo trên UI quản trị.
  • Bảo mật API Key: API Key cần được hiển thị dưới dạng che mặt (masked) sk-...xxxx khi truy vấn để tránh rò rỉ dữ liệu.
