Solution Architecture — Vaults through the Engine

Song hành với implementation-plan.html. Nguyên tắc chủ đạo: vault không có đường đi tiền riêng — nó là một service_code nữa trong engine đã có.

1. Context

flowchart LR
  mob["📱 Vaults screens"] --> API["POST /v1/transactions/request\nservice_code=VAULT_SAVINGS"]
  mob --> VAPI["GET/POST /v1/vaults\n(chỉ metadata: label, target)"]
  API --> OG["🛡 OfferGuard\nlimits + auth method"]
  OG --> DP["🔀 Dispatcher\nplanWallets(user_to_vault)"]
  DP --> WE["🔀 Workflow Engine\ndef p2p_transfer · txn_type=vault_move"]
  WE --> LE["⚖️ Ledger\n2 legs: main ↔ vault"]
  VAPI --> DB[("wallets\npurpose='vault' · label")]
  DP --> DB

2. Main flow — nạp vào hũ

sequenceDiagram
  participant U as User
  participant A as API
  participant G as OfferGuard
  participant P as planWallets
  participant L as Ledger

  U->>A: request{VAULT_SAVINGS, amount, extra_params{vault_id, direction:deposit}}
  A->>G: Check(user, VAULT_SAVINGS, vault_move, amount)
  alt vượt hạn mức gói
    G-->>U: ERR_LIMIT_*
  end
  A->>P: planWallets("user_to_vault", input)
  P->>P: đọc vault_id + direction
  alt vault không thuộc user
    P-->>U: ERR_VAULT_NOT_FOUND
  end
  Note over P: deposit → debit main, credit vault
withdraw → đảo chiều
  P-->>A: {senderWalletID, receiverWalletID}
  A->>L: InsertTransaction(type=vault_move) + engine.Start (một tx)
  L-->>U: {transaction_id, auth_required}
  U->>A: confirm{transaction_id, pin}
  A->>L: MOVE_FUNDS → 2 bút toán

4. Data model delta

Không có bảng mới — vault là một ví. Chỉ nới ràng buộc và thêm cột mục tiêu.

erDiagram
  users ||--o{ wallets : owns
  wallets ||--o{ ledger_entries : journals
  wallets {
    string purpose "main | vault"
    string label "tên hũ, NULL với ví main"
    bigint target_amount "NEW, chỉ hiển thị"
    bigint balance "= SUM(ledger_entries)"
  }

Ràng buộc: UNIQUE (owner_type, owner_id, currency, purpose, label) cho vault, kèm partial unique index (owner_type, owner_id, currency) WHERE purpose='main' — vì label của ví main là NULL và trong Postgres NULL ≠ NULL, nếu không có index này thì một user có thể tạo nhiều ví main.
