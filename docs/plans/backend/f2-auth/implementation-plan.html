3. Schema changes

000009_auth (up/down): 3 bảng + 1 enum. refresh_tokens.family_id là chuỗi rotation — 1 login = 1 family; refresh dùng lại token đã used ⇒ revoke cả family (theft detection). audit_logs append-only theo quy ước (không trigger — khối lượng ghi cao, enforce bằng quyền + review).

6. Rollout & risk

  • JWT_SECRET bắt buộc trong env — fail-fast khi thiếu; đổi secret = mọi access token cũ chết sau ≤15' (chấp nhận).
  • Code bắt đầu phụ thuộc sqlc gen: dev phải go install github.com/sqlc-dev/sqlc/cmd/sqlc@latest rồi make sqlc trước build lần đầu — ghi vào README. CI đã tự generate.
  • OTP dev-mode: log code ra console khi APP_ENV=dev (không bao giờ ở env khác).
